---

## 📹 Загрузка и показ видеофайлов

Есть два способа добавлять видео:

### 1. Прямо на сайте через кнопку «Загрузить видео»:
* В верхней строке нажмите кнопку **«Загрузить видео»**.
* Выберите любой видеофайл (`.mp4`, `.mov`, `.webm`, `.m4v`) с вашего компьютера или iPhone.
* Сайт автоматически сгенерирует превью-кадр, добавит ролик в ленту и запустит воспроизведение.

### 2. Через папку в проекте (для постоянного размещения):
* Поместите ваш видеофайл в папку: `assets/videos/ваше_видео.mp4`.
* В файле [`js/projects-data.js`](js/projects-data.js) укажите:
```javascript
{
  id: 1,
  client: "Имя клиента / проекта",
  title: "Название ролика",
  category: "video",
  categoryLabel: "Видео",
  badge: "Shot on iPhone",
  year: "2026",
  mediaType: "video_file",
  mediaUrl: "assets/videos/ваше_видео.mp4",
  thumbnail: "https://ссылка-на-превью.jpg"
}
```
