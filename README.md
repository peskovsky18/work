# 🎬 Портфолио «Разнорабочий в медиа»

Стильный, авторский черно-белый сайт-портфолио в рисованной крафтовой эстетике (*Doodle / Indie Zine / Brutalism*).
Собрано на чистом стеке (HTML5, CSS3, Vanilla JS) — **0 рублей вложений**, никаких платных подписок и конструкторов.

---

## ⚡️ Быстрый просмотр на компьютере

Просто дважды кликните по файлу **`index.html`** в этой папке, и он откроется в любом браузере (Chrome, Safari, Firefox, Edge).

Либо запустите локальный сервер через встроенный в macOS Python:
```bash
python3 -m http.server 8000
```
И откройте в браузере: `http://localhost:8000`

## ✏️ Как редактировать контент и добавлять свои работы

Все данные о вас и ваших работах хранятся в одном удобном файле:
📂 **[`js/projects-data.js`](js/projects-data.js)**

### 1. Изменить информацию о себе (Имя, Telegram, почту, слоган):
В конце файла найдите объект `PROFILE_DATA`:
```javascript
const PROFILE_DATA = {
  name: "РАЗНОРАБОЧИЙ В МЕДИА",
  alias: "Ваше Имя",
  tagline: "Снимаю • Режу • Направляю",
  // ...
  contacts: {
    telegram: "https://t.me/ваш_логин",
    telegramUsername: "@ваш_логин",
    email: "ваш_email@gmail.com",
    // ...
  }
};
```

### 2. Добавить новый проект в галерею:
В массиве `PROJECTS` скопируйте любой блок проекта и заполните свои данные:
```javascript
{
  id: 9, // Уникальный номер
  title: "Название вашей работы",
  category: "video", // "video" | "photo" | "montage" | "web"
  categoryLabel: "🎬 Видео",
  year: "2024",
  client: "Имя клиента или Личный проект",
  role: "Ваша роль (напр. Режиссер, колорист)",
  description: "Короткое емкое описание задачи и результата.",
  tools: ["Sony FX3", "DaVinci Resolve", "Ритмический монтаж"],
  
  // Для видео (YouTube / Vimeo):
  mediaType: "youtube",
  mediaUrl: "https://www.youtube-nocookie.com/embed/ID_ВАШЕГО_РОЛИКА",
  
  // Превью-картинка карточки (ссылка или локальный файл assets/images/...):
  thumbnail: "https://ваш-сайт.com/preview.jpg",
  
  tags: ["Реклама", "4K", "Клип"]
}
```

### 3. Форматы медиа:
* **YouTube видео:** укажите `mediaType: "youtube"` и ссылку вида `https://www.youtube-nocookie.com/embed/ВАШ_ID`. Ролики можно загружать на YouTube с параметром *«Доступ по ссылке»* (Unlisted) — они не будут видны в общем поиске, но отлично покажутся на вашем сайте.
* **Серия фотографий:** укажите `mediaType: "image"` и массив ссылок в поле `gallery: ["фото1.jpg", "фото2.jpg", "фото3.jpg"]` — в модальном окне появится удобное переключение кадров.
* **Веб-проект / Креативный дирекшн:** укажите `mediaType: "web"` и добавьте ссылку в поле `externalLink: "https://ссылка-на-проект.com"`.

## 🚀 Как бесплатно опубликовать сайт в интернет (0 ₽)

### Способ 1: Drag-and-Drop на Netlify Drop (самый простой, 1 минута)
1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop) (регистрация бесплатная).
2. Перетащите папку `портфолио апп` прямо в окно браузера.
3. Готово! Вы сразу получите рабочий адрес сайта вида `ваше-название.netlify.app` с бесплатным SSL-сертификатом.

### Способ 2: GitHub Pages (надежно и навсегда)
1. Создайте бесплатный аккаунт на [github.com](https://github.com).
2. Создайте новый репозиторий, например `my-portfolio`.
3. Загрузите файлы сайта в репозиторий.
4. В настройках репозитория (*Settings -> Pages*) выберите ветку `main` и нажмите **Save**.
5. Через 1 минуту ваш сайт будет доступен по адресу: `https://ваш-логин.github.io/my-portfolio/`.

### Способ 3: Vercel (быстро через браузер или CLI)
1. Зайдите на [vercel.com](https://vercel.com) (бесплатно).
2. Нажмите **Add New Project** и привяжите ваш репозиторий GitHub.
3. Нажмите **Deploy**.
